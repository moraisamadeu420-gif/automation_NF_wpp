Política de Privacidade

Última atualização: 20 de maio de 2026

1. Sobre o Serviço

O Bot NFS-e SPX é um serviço de automação para emissão de Notas Fiscais de Serviço Eletrônicas (NFS-e) para motoristas parceiros da plataforma SPX Driver. O serviço opera por meio do WhatsApp.

2. Dados Coletados

Para a prestação do serviço, coletamos os seguintes dados:

  • Número de telefone do WhatsApp
  • Nome completo
  • CPF/CNPJ de acesso ao portal NFS-e
  • Senha de acesso ao portal NFS-e
  • CNPJ do prestador de serviços
  • Município de prestação de serviços
  • Histórico de notas fiscais emitidas

3. Uso dos Dados

Os dados coletados são utilizados exclusivamente para:

  • Autenticação no portal NFS-e em nome do usuário
  • Emissão automatizada de notas fiscais
  • Envio do PDF da nota fiscal via WhatsApp
  • Manutenção do histórico de emissões

Seus dados jamais serão vendidos, compartilhados ou utilizados para qualquer outra finalidade.

4. Segurança dos Dados

As credenciais de acesso ao portal NFS-e são armazenadas com criptografia. Apenas o sistema automatizado tem acesso a essas informações para realizar as emissões autorizadas pelo usuário.

5. Seus Direitos (LGPD)

Em conformidade com a Lei Geral de Proteção de Dados (Lei nº 13.709/2018), você tem direito a:

  • Acessar seus dados armazenados
  • Solicitar a correção de dados incorretos
  • Solicitar a exclusão de todos os seus dados
  • Revogar o consentimento a qualquer momento

Para exercer esses direitos, envie a mensagem "excluir meus dados" para o bot no WhatsApp.

6. Retenção de Dados

Os dados são mantidos enquanto o usuário utilizar o serviço. Após a solicitação de exclusão, todos os dados são removidos em até 7 dias úteis.

7. Contato

Para dúvidas sobre esta política de privacidade, entre em contato pelo WhatsApp do serviço.
