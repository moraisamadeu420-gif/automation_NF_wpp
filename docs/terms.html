2. Descrição do Serviço

O Bot NFS-e SPX é um serviço de automação que realiza a emissão de Notas Fiscais de Serviço Eletrônicas (NFS-e) em nome do usuário, por meio do portal oficial da Receita Federal (Emissor Nacional NFS-e), utilizando as credenciais fornecidas pelo próprio usuário.

3. Responsabilidades do Usuário

  • Informar valores corretos dos serviços prestados
  • Manter suas credenciais do portal NFS-e seguras
  • Verificar as notas emitidas periodicamente
  • Cumprir com todas as obrigações fiscais perante os órgãos competentes

4. Responsabilidades do Serviço

  • Realizar a emissão das notas fiscais conforme os dados informados
  • Armazenar as credenciais com segurança e criptografia
  • Enviar o PDF da nota fiscal após a emissão
  • Manter o histórico de emissões

O serviço não se responsabiliza por:

  • Erros decorrentes de credenciais incorretas fornecidas pelo usuário

6. Uso das Credenciais

O usuário autoriza expressamente o serviço a utilizar suas credenciais do portal NFS-e exclusivamente para a emissão de notas fiscais solicitadas via WhatsApp. As credenciais nunca serão utilizadas para qualquer outra finalidade.

7. Cancelamento

O usuário pode cancelar o serviço a qualquer momento enviando a mensagem "cancelar" para o bot no WhatsApp. Todos os dados serão excluídos em até 7 dias úteis.
